Manushree Sane Portfolio

A responsive single-page React portfolio showcasing my skills, projects, and professional profile.

Features

- Responsive design
- About Me section
- Skills and technologies
- Projects showcase
- Contact information

Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

npm install

4. Start the development server:

npm run dev

Build Project

npm run build

The production-ready files will be generated inside the "dist" folder.

Deployment

This portfolio can be deployed using GitHub Pages with GitHub Actions.
